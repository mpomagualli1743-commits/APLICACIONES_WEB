
# Calculadora Web

## Descripción
Proyecto académico correspondiente a la Actividad 3.
Consiste en el desarrollo de una calculadora web funcional
utilizando HTML5, CSS3 y JavaScript.

## Objetivo
Aplicar conocimientos de desarrollo web del lado del
cliente mediante la creación de una aplicación interactiva.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git y GitHub

## Características
- Suma, resta, multiplicación y división.
- Cálculo de porcentajes.
- Operaciones con decimales.
- Cambio de signo.
- Borrado de caracteres.
- Historial de operaciones.
- Modo claro y oscuro.
- Soporte para teclado físico.
- Validación de errores matemáticos.
- Diseño adaptable a dispositivos móviles.

## Estructura del proyecto

calculadora-web/
- index.html
- css/styles.css
- js/script.js
- README.md

## Ejecución
Abrir el archivo index.html con Live Server
desde Visual Studio Code.
